# Лог решений (проектный уровень)

Формат записи: `[дата время] — решение — обоснование — версия package.json`. Время — по местному времени клиента (IST, Ирландия), см. `templates/`.

Этот файл — **публичный**, репозиторий открытый: сюда попадают только решения об архитектуре и процессе проекта. Решения, касающиеся конкретного клиента (его цели, программа, план питания), фиксируются в `clients/<slug-клиента>/decisions-log.md` — эта папка в `.gitignore` и наружу не публикуется.

## 2026-08-25 23:06 IST — версия 0.1.0

- **Решение:** заложена структура проекта (анкета клиента, программа тренировок, план питания, логи решений/вопросов/задач) и `package.json` для версионирования.
- **Обоснование:** проект будет дорабатываться итеративно (новые данные клиентов, корректировки программ по прогрессу), нужен фундамент, который не придётся перестраивать при росте проекта.

- **Обоснование:** клиентов несколько, каждому нужна отдельная папка вместо одной общей.
- **Решение:** заведена первая карточка клиента (см. `clients/index.md` — данные не публикуются, репозиторий публичный).

## 2026-08-26 06:40 IST — версия 0.3.0

- **Решение:** шаблон анкеты вынесен из `docs/` в отдельную папку `templates/` (`templates/questions-template.md`) — клиенты и переиспользуемые шаблоны физически разнесены по разным папкам верхнего уровня (`clients/` vs `templates/` vs `docs/`).
- **Решение:** папка `clients/` целиком добавлена в `.gitignore` — персональные данные клиентов (имена, города, здоровье, антропометрия) не должны попадать в git-историю.
- **Обоснование:** явный запрос — разнести клиентов и шаблоны по разным папкам и не пускать данные клиентов в git.
- **Заметка на будущее:** зафиксирована задача перенести все данные (клиенты, анкеты, программы, планы питания) из markdown в базу данных; конкретная СУБД пока не выбрана — см. `docs/todo.md`.
