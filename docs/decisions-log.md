# Лог решений (проектный уровень)

Формат записи: `[дата время] — решение — обоснование — версия package.json`. Время — по местному времени клиента (IST, Ирландия), см. `templates/`.

Этот файл — **публичный**, репозиторий открытый: сюда попадают только решения об архитектуре и процессе проекта. Решения, касающиеся конкретного клиента (его цели, программа, план питания), фиксируются в `clients/<slug-клиента>/decisions-log.md` — эта папка в `.gitignore` и наружу не публикуется.

- **Решение:** проект завёрнут в Docker — добавлены `Dockerfile` (образ бота) и `docker-compose.yml` (сервис `bot` + опциональный сервис `mysql` за Compose-профилем `local-db`).
- **Решение:** выбрана MySQL как СУБД (закрывает часть задачи "перенести данные в БД" из `docs/todo.md` — выбор конкретной СУБД сделан, схема и миграция данных клиентов — ещё нет).

Логика — `src/config.js` (чтение и разбор переменных) и `src/db.js` (пул соединений через `mysql2`).
- **Обоснование:** явный запрос — завернуть проект в Docker и дать удобный единый конфиг для подключения к MySQL, с поддержкой и локальной, и VPS-базы.
- **Статус:** подключение к БД пока нигде в коде бота не используется (`src/db.js` не импортируется в `src/bot.js`) — это задел на будущее, когда появится реальная работа с данными. Docker-образ не собирался и не тестировался — на машине разработчика не установлен Docker/Node.js.
