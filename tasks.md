# Tasks (запланировано / на подумать)

Публичный файл — сюда попадают только задачи и открытые вопросы уровня всего проекта, без персональных данных клиентов (для них — `clients/<slug-клиента>/todo.md`). В отличие от `docs/todo.md` (чек-лист без дат), здесь каждая запись — со временной меткой, привязана к конкретному коммиту/сессии и попадает сюда, когда в коммите на это есть только ссылка (см. `README.md` → «Коммиты»).

Формат: `[дата время] — коммит/версия — что запланировано / над чем подумать`.
