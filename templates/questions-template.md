# Шаблон: первичная анкета клиента

Общий шаблон для всех новых клиентов. Перед первым разговором с клиентом:
1. Скопировать этот файл в `clients/<slug-клиента>/questions-log.md`.
2. Перед 15 вопросами сначала узнать **имя** и **город** клиента и завести карточку `clients/<slug-клиента>/profile.md`.
3. По мере ответов — обновлять колонку «Ответ» и статус, затем перенести данные в `profile.md`.

Формат записи: `[дата] #N — вопрос — статус (задан / отвечен) — ответ`.

## Как обновлять
- При получении ответа — обновить колонку «Ответ» и сменить статус на «отвечен».
- Каждый новый раунд уточняющих вопросов (например, после первых недель тренировок) добавлять отдельным разделом с датой в файле клиента (`clients/<slug-клиента>/questions-log.md`), не в этом шаблоне.
- Этот файл (`templates/questions-template.md`) не редактируется данными конкретного клиента — только структурные правки самого шаблона.
